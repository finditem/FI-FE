# 찾아줘! 기능 명세서 색인

기능 명세서의 원본은 Confluence의 두 페이지이다. 이 파일은 기능 ID, 카테고리, 기능명, 디자인 시안명을 한곳에서 찾기 위한 색인이며, 기능 설명, 상세 정책, 예외 처리, 1차와 2차의 변경점은 Confluence 페이지의 값을 따른다.

## 작성 규칙

- 기능 ID는 `FNC-일련번호`이며 삭제한 ID는 다시 쓰지 않는다. (기획 문서 컨벤션)
- 1차와 2차에 모두 있는 기능은 기능 ID, 카테고리, 기능명, 기능 설명, 상세 정책, 예외 처리, 디자인 시안이 두 문서에서 같다.
- 1차에서 2차로 달라진 내용은 비고의 `[1차→2차 변경점]`에 번호로 적는다. 코드로 확정하지 못한 동작은 `[확인 필요]`, 화면 이름으로 추정한 내용은 `[추측]`으로 구분한다.
- 우선순위는 아직 비어 있다.
- 디자인 시안명은 `기능ID_카테고리_기능명` 형식이며 공백이 없다. 시안 이름이 아직 Figma 프레임과 연결되지는 않았다.

## 요약

- 총 기능 71개. 두 문서 공통 57개, 2차에서 새로 생긴 기능 7개(FNC-006, 031, 039, 040, 041, 042, 051), 2차에서 이 프로젝트에서 빠진 관리자 기능 7개(FNC-065~071).
- 2차 문서는 FNC-001~064의 64개, 1차 문서는 공통 57개와 관리자 7개를 합한 64개를 담고 있다.
