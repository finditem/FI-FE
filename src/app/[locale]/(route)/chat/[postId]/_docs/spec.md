# 채팅 메시지 번역 기획 스펙

> 원본: Confluence 위키 (인증 필요로 직접 열람 불가하여 사용자가 텍스트로 전달, 2026-09-08 기준)

## 채팅 메시지 번역

### 2-1 번역하기 아이콘 선택 시

해당 메시지를 사용자 설정 언어로 번역

### 2-2 원문 보기 아이콘 선택 시

해당 메시지를 원문으로 나타냄

## 채팅 번역 실패

번역에 실패한 경우 상단 3-1 Toast 노출

### 3-1 Toast

"번역에 실패했어요. 다시 시도해주세요", 3초 노출

실패 시 메시지는 원문 상태를 유지하며 번역 아이콘을 통해 재시도할 수 있다.

## 번역 횟수 표시

### 4-1 번역 횟수 표시

N(사용자가 사용한 횟수) / 20(하루동안 사용할 수 있는 횟수) 형식으로 노출

번역이 정상적으로 완료된 경우에만 사용 횟수를 1회 차감. 번역 실패 건은 사용 횟수에 포함하지 않음.

## 번역 횟수 제한 정책

- 번역 횟수는 계정당 최대 20회로 제한됨
- 메시지 1건의 번역 완료 시 번역 횟수 1회를 차감
- 번역 횟수가 20회에 도달한 상태에서 추가 번역을 시도할 경우 5-1 Toast를 노출
- 채팅방 재진입 후 이전에 번역했던 동일 메시지를 다시 번역하는 경우에도 신규 번역 요청으로 처리하므로 번역 횟수 제한 정책을 동일하게 적용한다

### 번역 완료 메시지 유지 규칙

- 번역이 완료된 메시지는 현재 채팅방을 유지하는 동안 번역된 상태로 노출
- 번역 횟수 제한에 도달하더라도 현재 채팅방에서 이미 번역이 완료된 메시지는 계속 확인할 수 있음
- 번역 완료 여부 및 번역 결과는 채팅방 재진입 시 유지하지 않음

예시:

1. 메시지 A 최초 번역 → 1회 차감
2. 채팅방 내에서 메시지 A 재확인 → 추가 차감 없음
3. 채팅방 이탈 후 재진입 → 메시지 A 원문으로 초기화
4. 메시지 A 다시 번역 → 1회 추가 차감

### 5-1 Toast

- 상단: 번역 횟수를 모두 사용했어요.
- 하단: {N}시간 후 다시 사용할 수 있어요. 번역한 메시지는 계속 볼 수 있어요.
- {N}시간은 사용자의 번역 이용 이력을 기준으로 다시 번역할 수 있는 시점까지 남은 시간을 계산하여 노출한다.

## 신규 메시지 수신/전송

- 기존 메시지가 번역된 상태에서 신규 메시지를 수신하거나 전송해도 기존 번역 상태를 유지
- 신규 수신 메시지는 원문으로 노출하며, 사용자가 직접 번역 아이콘을 선택한 경우에만 번역

## 채팅 번역 공통 정책

- 설정 언어가 한국어인 경우 한국어, 영어인 경우 영어로 번역
- 번역 완료 시 해당 메시지 영역에 번역된 채팅 메시지를 노출

### 번역 적용 범위

- 번역은 채팅 메시지 본문을 대상으로 메시지 단위로 적용
- 사용자 닉네임, 시간 정보 등 사용자 고유 정보 및 메타 정보는 번역하지 않고 원문 그대로 노출
- 입력창 Placeholder, Toast 등 시스템 UI 문구는 사용자 설정 언어에 따라 한국어 또는 영어로 노출

### 번역 상태 및 횟수 정책

- 이미 번역된 메시지는 채팅방 내에서 번역된 상태를 유지
- 일일 번역 가능 횟수는 매일 초기화
